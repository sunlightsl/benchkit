创建 formatTable.mjs，导出 formatTable(rows, aligns)：把二维字符串数组渲染成 GitHub 风格 Markdown 表格。规则：列宽 = 该列所有单元格的最大字符数（含表头行，表头是 rows[0]）；单元格格式为 `| ` + 内容 + 右侧空格补齐到列宽 + ` `；分隔行的每个单元格就是三个标记本身、固定长度、不按列宽补齐——left 为 `---`，right 为 `---:`，center 为 `:--:`，单元格两侧仍各带一个空格（如 `| --- |`、`| ---: |`）；空单元格按空字符串处理再补齐；最后一行以换行结尾。模块不要打印输出。
